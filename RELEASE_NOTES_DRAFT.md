# Portfolio preview — v0.2.0-beta (draft)

This pre-release documents the current cross-platform Aishu Art Studio prototype. It is **not a production download**.

### Included in the public portfolio
- Project overview and screenshots.
- Case study, architecture notes and current testing status.
- Release checklist and development roadmap.

### Tested
- Windows and native Mac applications open.
- Android Pocket V2 installs and launches.
- Basic Windows ↔ Android idea updates; Windows → Android planner visibility.

### Still in testing
- Real Windows ↔ Mac sync through Google Drive for desktop.
- Mac ↔ Android pairing; full image/progress media transfer; offline conflict policy.

No app binaries are attached to this showcase release.
